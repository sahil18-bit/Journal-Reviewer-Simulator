HybridNet: A CNN-LSTM Model for Early Diabetes Prediction from Clinical Records Abstract Diabetes affects millions of people worldwide and early prediction can reduce complications. We propose HybridNet, a hybrid deep learning model that combines a convolutional feature extractor, an LSTM module and an attention mechanism. On the Pima Indians Diabetes dataset HybridNet achieves 96.4% accuracy and significantly outperforms existing methods, achieving state-of-the-art performance. Our results show that high glucose levels cause diabetes onset, and the model generalizes to any hospital population. 1. Introduction Machine learning has been widely applied to medical diagnosis. Earlier studies used logistic regression, decision trees and support vector machines. Deep learning models can learn complex interactions between clinical variables without manual feature engineering. In this paper we make three contributions: (1) the HybridNet architecture, (2) a complete preprocessing pipeline, and (3) an evaluation showing superior performance. 2. Methodology We use the Pima Indians Diabetes dataset, which contains 768 records with 8 clinical features. The dataset is imbalanced, with 268 positive and 500 negative cases. Missing values were replaced by the feature mean. All features were normalized using min-max scaling on the entire dataset. To handle class imbalance, SMOTE was applied to the full dataset before splitting. The data were then split into 80% training and 20% testing sets. HybridNet consists of three components: a 1-D convolutional block with 64 filters, an LSTM module with 32 units, and an attention mechanism, followed by a dense output layer. The model was trained with the Adam optimizer for 100 epochs. The number of epochs and the learning rate were selected based on the accuracy obtained on the test set. 3. Results Table 1 compares HybridNet with a support vector machine baseline. HybridNet achieves 96.4% accuracy compared with 89.1% for the SVM, which is a significant improvement.
